Settings

These change the web pages Once opens, not the story list.

Both are synced to your other devices, and every device runs them with whatever it has: the desktop app hands them to the uBlock Origin and Violentmonkey it ships with, phones run a smaller built-in version of each.

Filter lists

Ad and tracker lists in the usual uBlock/Adblock format, one list URL per line. Start a line with # to keep a list but switch it off. On the desktop they are added to the lists uBlock Origin already uses, so nothing you selected there is lost. On a phone Once applies them itself and reads only plain blocking and hiding rules — exceptions (@@), scriptlets and procedural selectors are skipped, and iOS caps how many rules it will take.

Userscripts

All userscripts as text

Every script one after another, each starting with its own // ==UserScript== header — the quickest way to paste several at once. Add // @once-disabled inside a header to keep a script but switch it off.
